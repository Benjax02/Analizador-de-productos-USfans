# Analizador-de-productos-USfans
Web en español "Analizador de productos USFans": formulario (link, tipo, precios, texto pegado) que llama a /api/analyze y muestra veredicto original/dudoso/réplica, % de autenticidad y calidad, alertas y recomendación. API con Gemini (gemini-2.5-flash-lite) y GEMINI_API_KEY como variable de entorno. Historial local. Diseño verde.
